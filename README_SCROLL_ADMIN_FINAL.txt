ORIAVISION HUB - SCROLL REAL + ADMIN CONSERVADO

Qué incluye:
- Se conserva /admin/ del proyecto original.
- Se conserva content/prompts/ y content/guides/.
- Se conservan las páginas /prompts/ y /guias/.
- La home fue remodelada con la animación por scroll nueva.
- El buscador del hero usa herramientas + prompts + guías reales del proyecto.
- Las secciones de Prompts y Guías toman contenido editable desde getAllPromptsMerged() y getAllGuidesMerged().
- No se agregaron librerías nuevas de animación.

Para probar:
npm install
npm run dev
