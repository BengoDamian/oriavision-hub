Privacidad y reservas

Aluna es un estudio de ejemplo. Su marca, equipo, dirección y teléfono inicial son ficticios. Para probar el sistema, podés usar datos de ejemplo.

Datos de tu reserva

El sistema guarda nombre, correo, teléfono y datos de la clase para gestionar tu lugar y mostrarlo en la agenda privada del estudio. No se solicitan datos de tarjetas ni información de salud.

Tu comprobante

La confirmación se muestra en pantalla. El enlace del comprobante es privado: permite consultar y, hasta 12 horas antes, cancelar la reserva. Guardalo y no lo publiques.

Pago y cancelación

No se cobra una seña online. La clase se abona en el estudio. Una cancelación libera el lugar para otra persona. Las modificaciones dentro de las 12 horas previas se gestionan con el estudio.

Consultas y mensajes

No se envían correos ni mensajes de WhatsApp automáticamente. Cuando se configure el teléfono real del estudio, el botón de consulta abrirá WhatsApp y vos decidirás si enviar el mensaje.

Acceso a los datos

La administración del estudio puede ver los datos de las reservas. Para consultar o solicitar la eliminación de tus datos, contactá a quien te compartió esta propuesta.
